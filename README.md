# 🌌 ANTI-GRAVITY SUCCESS MANAGEMENT SYSTEM (AG-SMS & SOS)

> **소크라테스식 산파술과 5대 거장의 성공 철학을 융합하여, 무의식의 열망과 심리적 저항(Gravity)을 발굴하고 불변의 If-Then 의사결정 헌법 및 실전 지상 행동으로 전환하는 초격차 개인 맞춤형 성공 관리 운영체제**

---

## 🏛️ 4개 계층 심층 성공관리 파이프라인 아키텍처

```
[1단계: 잠재의식 발굴] (토니 로빈스 & 나폴레온 힐)
  │  소크라테스식 파워 질문 → 핵심 가치 추출 → 명확한 중심 목표(DCA) 수렴
  ▼
[2단계: 지식 및 맥락 구조화] (티아고 포르테)
  │  대화 로그 캡처(C) → PARA 분류(O) → 본질 요약(D) → 실행 자산화(E)
  ▼
[3단계: 수직적 행동 정렬] (데이비드 앨런)
  │  50,000ft(존재 이유/정체성) ──▶ Runway(오늘의 3분 지상 실행/Next Action)
  ▼
[4단계: 원칙화 및 피드백 루프] (레이 달리오)
  │  실행 결과 진단 → 5-Whys 근본 원인 분석 → If-Then 의사결정 알고리즘 자동 갱신
  └───────────── (누적된 원칙이 다시 1단계 질문 엔진을 고도화) ─────────────┘
```

---

## 🌟 핵심 시스템 모듈 & 주요 기능

### 1. 🤖 소크라테스식 꼬리에 꼬리를 무는 질문(꼬꼬무) 엔진
- **세트 1 (구조화 파워 질문)**: 5대 거장 체계 기반 소크라테스식 3지선다형 질문
- **세트 2 (꼬리 질문 & 전문가 처방전)**: 작성자의 답변을 실시간 인지 분석하여 반사 질문 및 통찰 처방전 자동 생성
- **🎨 7대 네온 프리셋 컬러 피커**: 질문 박스 및 테두리 색상 자유 조정 (`localStorage` 영구 보존)
- **✏️ 인라인 문구 편집기**: `[ ✏️ 글씨/문구 변경 ]`을 통해 사용자가 질문과 처방전 텍스트를 즉시 수정 및 저장 가능

### 2. 🏛️ 4개 계층 심층 성공관리시스템 (우측 워크스페이스)
- **Tier 1 (잠재의식)**: 소크라테스식 파워 질문 ➔ 핵심 가치 추출 ➔ DCA 목표 수렴 + Pain vs Pleasure 신경학적 지렛대
- **Tier 2 (지식구조화)**: CODE 파이프라인 (Capture ➔ Organize PARA ➔ Distill ➔ Express)
- **Tier 3 (수직행동정렬)**: GTD Horizons of Focus (50,000ft 존재이유 ➔ 10,000ft 프로젝트 ➔ 지상 Runway 3분 실행 미션 + 타이머)
- **Tier 4 (원칙화 루프)**: 5-Whys 근본 진단 ➔ 기계론적 시스템 설계 ➔ If-Then 헌법 ➔ 1단계 질문 자동 고도화 선순환 루프

### 3. 📑 5대 시스템종합 데이터 아키텍처 매트릭스
- **전문가 인지 진단**: 축적 대화 기반 3대 핵심 축(Need - 표면 병목 5-Whys - Runway 3분 실행) 실시간 진단
- **5대 거장 비교 매트릭스 표**: 달리오, 로빈스, 포르테, 힐, 앨런의 핵심 원리와 실전 라이브 산출물 양방향 바인딩
- **Executive Action Directives**: 아침 07:00 / 낮 13:00 / 밤 22:00 3대 시간대별 행동 수렴 지침 제시

### 4. ⚡ 3분 실전 행동연계 관제탑 & 🔔 실시간 소셜 알람 허브
- **3분 지상 최소 물리 행동 (Runway)**: 착수 마찰 계수 제로화를 위한 3분 타이머 및 카운트다운 가동
- **소셜 알람 파이프라인**: 이메일, 카카오톡, 텔레그램, 웹훅 실시간 설정 및 발송 데이터 프리뷰 지원

### 5. 🔤 전역 최소 10pt 보장 및 100% 실시간 폰트 스케일링
- 웹/조판 타이포그래피 표준 **10pt(13.5px)를 전역 절대 최소 하한선**으로 설정
- 각 탭 및 섹션 상단 컨트롤러(`[ - % + ]`)를 통해 모든 표, 카드, 본문 글씨를 0.1초 만에 실시간 확대/축소

```bash
git clone https://github.com/tttd1us-design/anti-gravity-sos.git
cd anti-gravity-sos

# 로컬 웹 서버 실행 (Python 3)
python -m http.server 8080

# 웹 브라우저 접속
# http://localhost:8080
```
