# 🌌 ANTI-GRAVITY SUCCESS MANAGEMENT SYSTEM (AG-SMS)

## 🚀 3단계 파이프라인 아키텍처

1. **소크라테스식 탐색 (Socratic Probing Arena)**:
   - 표면적 답변 뒤에 숨은 본원적 결핍과 두려움을 파헤치는 5단계 심층 산파술 질의 트리.
   - 단 하나의 깊이 있는 질문으로 주도권을 넘기는 1-Question 프로토콜.

2. **데이터 축적 및 패턴화 (Subconscious Knowledge Vault)**:
   - 본원적 열망 가중치 맵 (Core Desires Radar).
   - 행동을 가로막는 보이지 않는 심리적 저항 패턴 (Gravity Friction).
   - 나폴레온 힐의 명확한 중심 목표 (Definite Chief Aim: DCA) 공식화.
   - 티아고 포르테의 PARA 지식 분류 체계 연동.

3. **행동 원칙 및 실행 엔진 (Action & Dalio Engine)**:
   - 데이비드 앨런 GTD 6-Horizons 수직 정렬 (50,000ft 정체성 ~ Runway 당장 착수할 2분 행동).
   - 레이 달리오 If-Then 의사결정 알고리즘 자동 추출 및 검색.
   - 영구 LocalStorage 보존 및 Notion/Obsidian 호환 Markdown & JSON 내보내기.
